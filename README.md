# nauta

Línea de comandos para el nauta hogar Cuba

> Nota: El nombre `nauta` en PyPI fue donado, por lo que este proyecto se publica como `nauta-hogar`.

## Instalación con pipx

Para instalar `pipx` siga las [instrucciones](https://github.com/pypa/pipx#install-pipx) según su sistema operativo

```bash
pipx install nauta-hogar --force
```

## Guía

1. Agregar un usuario

```console
nauta add micorreo@nauta.com.cu contraseña
```

1. Iniciar sesión

```console
nauta login
```

1. Cerrar sesión

```console
nauta logout
```

## Ayuda

```bash
nauta --help
```

## Desinstalación

```bash
pipx uninstall nauta-hogar
```

## Actualización

```bash
pipx upgrade nauta-hogar
```
